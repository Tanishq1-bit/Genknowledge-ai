📄 GenKnowledge AI

Chat with your study material. Upload a PDF, ask questions and get answers grounded in the document, with page numbers. Generate multiple-choice quizzes from the same PDF to test yourself.

Features
Chat with a PDF: answers come only from the uploaded document. If the answer isn't there, the assistant says so instead of guessing.
Page-numbered sources: every answer shows which pages and text chunks it was based on.
Quiz mode: generate 3 to 10 multiple-choice questions on a topic from the PDF, with a score and explanations.
Conversation memory: follow-up questions work, using the last 8 messages as context.
REST API: the AI logic runs in a FastAPI backend, separate from the Streamlit UI. Interactive docs at /docs.
Dockerized: the whole app starts with one command.
